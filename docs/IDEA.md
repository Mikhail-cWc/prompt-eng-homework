# Супергерои — проклятие

Пользователь предложил тему коллекции «Супергерои — проклятие»
и предложил эстетику сериала The Boys. Он предоставил постер «Когда он видит вас»
как визуальный ориентир. Сам постер — пользовательский референс, не результат работы
агентной системы: [reference-poster.png](reference-poster.png).

## Художественное решение

Ограниченная палитра: угольно-чёрный, киноварно-красный, грязный кремовый.
Высокий контраст, растровая печать, фотомонтаж, потёртая бумага, вертикальный формат.
Общая тема — сверхсила без ответственности. Контраст между обещанием защиты
и фактическим контролем строится через масштаб и конкретную визуальную метафору.
Новые вымышленные герои; названия расположены в галерее рядом с изображениями.

1. «Под защитой»: щит над пустым городом отбрасывает тень-решётку.
2. «Цена спасения»: парадный образ героя соседствует с утратой обычного дома.
3. «Герой по подписке»: платёжный барьер между нуждающимся и рукой помощи.
4. «Культ на конвейере»: фабрика одинаковых масок и один перевёрнутый экземпляр.

Первая концепция «Под защитой» с гигантским героем и лучами взгляда была отклонена
Images API. Её диалог и отказ сохранены отдельно в `outputs/01-surveillance/rejected-concept/`.
Для основной коллекции разработана другая композиция — предметная аллегория со щитом.
Сцена «Наследники культа» с подростковыми силуэтами тоже отклонена API; её заменила
предметная композиция «Культ на конвейере» без живых людей. Исходная попытка
сохранена в `outputs/04-cult/rejected-concept/`.

## Агентный процесс

Куратор формулирует метафору; художник обсуждает композицию и составляет промпт;
Yandex ART генерирует изображение; VLM рассматривает настоящие пиксели и предлагает
правки. После второй генерации VLM сравнивает обе версии. Оценки субъективны,
а выбор первой версии разрешён. Дополнительная интерпретация первого сюжета
выполняется локальной SD-Turbo с весами Hugging Face.

Визуальные признаки референса описаны coding-агентом в STYLE. Сам PNG не передаётся
в генератор как image-to-image: новые изображения создаются по текстовым промптам.
